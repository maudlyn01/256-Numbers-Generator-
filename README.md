# 🎲 Gerador de 256 Números Aleatórios

Uma aplicação web desenvolvida com **HTML5, CSS3 e JavaScript** que simula o lançamento de um dado, gerando automaticamente 256 resultados aleatórios entre 1 e 6.

## 📌 Funcionalidades

- 🎲 Geração de exactamente 256 números aleatórios.
- 🔢 Resultados limitados aos valores de 1 a 6.
- 🎨 Representação visual dos resultados em forma de dados.
- 🔄 Possibilidade de gerar uma nova sequência.
- 📋 Opção para copiar os resultados.

## 🛠️ Tecnologias utilizadas

- **HTML5** – Estrutura da aplicação.
- **CSS3** – Estilização e representação visual dos dados.
- **JavaScript (ES6+)** – Lógica de geração.

## 🚀 Como executar

1. Clonar o repositório:

   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Entrar na pasta do projecto:

   ```bash
   cd random-dice-generator
   ```

3. Abrir o ficheiro `index.html` no navegador.

Não é necessária a instalação de dependências adicionais.

## 🎯 Objectivo

Demonstrar a utilização de JavaScript na geração de números aleatórios, manipulação do DOM, processamento de dados através de uma interface gráfica interactiva.
